## Closed canary records

The harness uses an isolated CLI-only world, read-only inputs, a per-session
installation of the exact revised wheel and fresh isolation proof. It does not
mount outcome corpora or use port8471. Each completed run checks26 isolation
invariants before and after. The relay reserves budget before forwarding and
settles only authenticated complete upstream usage records; uncertain requests
retain their reservation. The authorized total cap is$10.

Recorded receipts are operator-held local artifacts, not included physical data.
`reference-lab-canaries.json` binds the audited receipts and tested wheels. Public
readers can inspect this summary and code, but should not infer access to private
receipts or independent reproduction. Two early harness incidents are retained:
PR2's first isolation check stopped before provider calls; PR3 had a transport
failure and native continuation after relay error handling was corrected. They
are execution incidents, not scientific results.
