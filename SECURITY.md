# Security Policy

## Supported versions

Only the current release receives security updates.

| Version | Supported |
| --- | --- |
| 0.1.14 | Yes |
| Earlier versions | No |

## Report a vulnerability

Report security issues privately to
[info@dynamicalsystems.ai](mailto:info@dynamicalsystems.ai). Include the affected
version, the impact, and steps to reproduce the issue when possible.

Do not publicly disclose instrument-safety issues or authority-bypass issues
before you coordinate disclosure with Dynamical Systems Research.
